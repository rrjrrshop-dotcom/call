# kiosk-help-screen (키오스크 안내 화면)

갤러리예지향 매장의 결제 실수를 예방하고 마감 정산 시간을 단축하는 한 페이지 웹 도구입니다.

---

## 1. 프로젝트 개요
- **도구 이름**: 키오스크 안내 화면
- **폴더·레포명**: `kiosk-help-screen`
- **기업명**: 갤러리예지향
- **한 줄 컨셉**: 결제 실수를 줄이는 키오스크 안내 도구 (16자)
- **사용 목적**: 고객의 결제 오류를 사전 방지하고, 대표님·직원의 일일 마감 정산 시간을 대폭 단축
- **사용자**: 매장 대표님 1인 또는 직원 1~2명 (소수 운영)
- **배포 형태**: 정적 HTML 단일 파일 (Vercel 배포 가능, 로컬 즉시 실행 가능)

---

## 2. PRD 및 요구사항 정의

### ① 한 줄 컨셉 재진술
> **결제 실수를 줄이는 키오스크 안내 도구** (16자, 명사구)

### ② 1주 안에 만들 MVP 기능 3개
1. **[키오스크 결제 안내 가이드]**: IC카드 삽입 방향, 간편결제 태그 위치, 영수증 수령 등 실수 빈번 단계를 시각적으로 전달하는 3단계 안내 화면
2. **[일일 마감/정산 간편 계산기]**: 키오스크 승인 합계, 취소/환불액, 실제 정산액을 입력해 오차(차액)를 즉시 산출하는 마감 계산기
3. **[정산 내역 저장 및 CSV 다운로드]**: 입력된 일별 정산 데이터를 브라우저 `localStorage`에 자동 보관하고 엑셀(CSV)로 1초 만에 내려받는 기능

### ③ ‘v2 이후’로 미루는 기능 2~3개
- **주간·월간 매출 추이 비교 및 그래프 시각화** (이유: 우선순위 — 1주 차엔 마감 실수 방지가 최우선)
- **POS/VAN사 키오스크 API 실시간 자동 연동** (이유: 연동복잡도 — 하드웨어 및 밴사 인증 승인 지연 방지)
- **직원별 교대 근무 정산 및 권한 분리 로그인** (이유: 범위초과 — 1~2인 소규모 운영 단계에서는 불필요)

### ④ 첫 화면 텍스트 와이어프레임 (모바일 360px 기준, 10줄 이내)
```text
[ 갤러리예지향 키오스크 도우미 ]
[안내 모드 | 마감 정산 모드]
--------------------------------
■ [결제 안내] 1.작품선택 > 2.카드삽입 > 3.영수증
■ [자주 묻는 질문] 취소/교환, 주차 등록, 모바일페이
--------------------------------
■ [오늘 마감] 2026-09-16 (화)
■ 키오스크 승인: [    0]원 | 취소: [   0]원
■ 실제 포스/입금: [    0]원 -> [차액: 0원]
--------------------------------
[ 마감표 저장 ]  [ CSV 엑셀 다운로드 ]
```

### ⑤ 파일 구조
```text
kiosk-help-screen/
├── index.html       # HTML 1파일에 UI, CSS(Tailwind), 로직(JS) 내장 (단독 배포 및 오프라인 실행 가능)
└── README.md        # 프로젝트 기획서, 데이터 구조 및 운영 매뉴얼
```
- **선정 이유**: 외부 서버 설치나 복잡한 빌드 과정 없이, 태블릿이나 스마트폰 브라우저에서 `index.html` 파일 하나만 열어도 즉시 작동하며, Vercel/GitHub Pages에 드래그 앤 드롭으로 10초 만에 배포 가능합니다.

### ⑥ 결정이 필요한 빈칸 3개
1. **[사용 대상 화면 분리 여부]**: 매장 방문 고객이 직접 터치하여 보는 '고객용 안내 키오스크 거치대 화면'과 사장님/직원 전용 '마감 정산표'의 화면 진입 경로를 PIN 번호 등으로 분리할 것인가?
2. **[마감 데이터 집계 단위]**: 마감 시 입력하는 데이터가 영수증 건별 개별 입력인지, 아니면 키오스크 마감 영수증 하단에 찍힌 '일일 합계 3가지(승인총액/취소총액/입금액)' 형태인지?
3. **[데이터 보관 환경]**: 정산 데이터를 매장 카운터 전용 기기 1대(브라우저 캐시)에만 보관할 것인가, 사장님 개인 스마트폰과 구글 시트 등으로 연동 동기화해야 하는가?

## 3. 데이터 입출력 명세

### 입력 예시 (Input)
```json
{
  "date": "2026-09-16",
  "approvedAmount": 850000,
  "cancelledAmount": 30000,
  "actualAmount": 820000,
  "orderCount": 42,
  "memo": "오후 도자기 전시 관람객 카드 재승인 1건 발생"
}
```

### 출력 예시 (Output)
- **순 매출액 (Net Sales)**: 820,000원 (`approvedAmount - cancelledAmount`)
- **정산 오차 (Difference)**: 0원 (`actualAmount - Net Sales`) -> *정상 마감 일치*
- **다운로드 형식**: `kiosk_closing_2026-09-16.csv`

## 4. 실행 및 배포
- 별도의 유료 API 키나 백엔드 서버가 필요 없습니다.
- 모든 데이터는 사용자의 로컬 브라우저 `localStorage`에 암호화 보관됩니다.
